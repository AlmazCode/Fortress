## Работает локально

- Production-сборка React и настоящий FastAPI на одном origin, http://127.0.0.1:8000/.
- Native Windows-профиль: очередь SQLite WAL на диске, один анализ, lease/fencing, OS GPU lock, отдельный процесс с дедлайном.
- Обученный uniform GRU-контроль подключён через сохранённый локальный пакет с проверкой SHA; новые ухудшившиеся кандидаты не используются.
- Настоящий MOV →202→processing→done, положительный и отрицательный ответы, genuine JPEG из исходного видео и H.264 preview.
- X-API-Key на API и медиа, 401 при неправильном ключе, 429 при конкурентном job. Ключ/конфигурация/веса/данные вне Git.
- В браузере проверены подключение к API, статус «Прототип», отображение результата/кадра и переход видео к1.5с.
- Windows Job Object завершает модель/FFmpeg вместе с родителем; timeout и parent-crash проверяются настоящими процессами.

Команды и требования: [LOCAL_SETUP](LOCAL_SETUP.md). Карточка подключения: [JURY_HANDOFF](JURY_HANDOFF.md).

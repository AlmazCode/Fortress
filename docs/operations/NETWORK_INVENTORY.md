# O1 — фактический инвентарь внешнего доступа

Дата проверки: 17 октября 2026 года. Проверяется текущий Windows-хост разработчика №4. Целевой сервер и другой training ПК не проверены. Координация выполняется через Git/GitHub, без Aster.

| Условие | Наблюдение | Статус |
| --- | --- | --- |
| Доменные имена сервиса | Пользователь не предоставил hostname или URL | blocked |
| Входящий разрешённый транспорт | Не предоставлен подтверждённый маршрут; firewall/port forwarding не менялись | unverified |
| Сертификат/цепочка/срок | Сертификат сервиса не предоставлен, соединение не запускалось | not_run |
| WAN и публичный IP | Адреса не предоставлены; сторонние IP-сервисы не опрашивались | unknown |
| CGNAT | Недостаточно данных для заключения | unknown |
| Ubuntu/WSL2 runtime | WSL сообщает, что не установлен | blocked |
| Docker daemon/Compose | Исполняемый файл Docker не найден в PATH | blocked |
| GPU на хосте | RTX 4060 Laptop, 8188 MiB, driver 595.79 | observed |
| GPU в Linux-контейнере | Docker недоступен; workload не запускался | not_run |
| Внешний HTTPS upload/status | Не выполнялся; нет подтверждённого URL/маршрута | blocked |

**Итог:** `external_access_verified=false`, `service_ready=false`, `gpu_ready=false`. Ни текущий инвентарь, ни будущая локальная TLS-проба не являются внешним smoke.

Дальнейшие условия: владелец предоставляет hostname, подходящий сертификат вне Git и разрешённый входящий маршрут; на целевом Ubuntu/WSL2 ПК подготавливаются Docker/Compose/GPU/FFmpeg. После K/O2 задача O3 выполняет synthetic внешний upload/status с независимого клиента. После интеграции I та же проверка повторяется в B на реальном API. Если маршрут невозможен из-за CGNAT/firewall, это остаётся обязательным network blocker, пока владелец не предоставит допустимый транспорт.

Для повторного сбора фактов — [PREFLIGHT.md](PREFLIGHT.md). Реальные видео, API-ключи и приватные ключи сертификатов в этих проверках не использовались. Полные локальные JSON-отчёты не включены в Git.

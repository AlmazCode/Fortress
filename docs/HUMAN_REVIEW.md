# Быстрая разметка на своём ПК

Дважды нажмите **Разметка.cmd** в корне репозитория. Откроется `http://127.0.0.1:8766/`. Это отдельный локальный разметчик; сервис анализа на8000 продолжает работать. Нужны уже установленная `.venv` и прежние подготовленные данные в `%USERPROFILE%\FortressArtifacts\training-ready`.

1. Выберите вопрос: сейф, положение сумки, действие, экран, присутствие людей. Начните с состояния сейфа, затем сумки и экрана на предложенных видео.
2. Для одного кадра нажмите кнопку ответа или клавишу1/2/3/4. Активный кадр выделен синей рамкой. Если включён автопереход, следующий кадр выбирается автоматически.
3. Для одинакового ответа нескольким кадрам отметьте их флажками. **A** выделяет всю видимую страницу; затем1/2/3/4 применяет ответ ко всем выделенным. Страница содержит12/24/48 кадров. Просмотрите выделенные кадры перед массовым ответом.
4. Нажмите кадр илиEnter для увеличения. **V** открывает5секунд видео вокруг исходного кадра, без звука. Ответ относится к выбранному кадру, а не ко всему ролику. Исходное время контекста показывается приблизительно; время/PTS самого кадра сохраняются точно.
5. **Ctrl+Z** или«Отменить» возвращает последнюю одиночную или массовую операцию. **N** находит первый кадр без ответа; ←/→ перемещают активный кадр; PgUp/PgDn переключают страницы. Горячие клавиши работают и при русской раскладке.

«Не видно / не уверен» — полноценный ответ: кадр проверен человеком, но обучающая цель остаётся unknown. Просто наличие сумки не означает действия с ней; сумка в руках не означает, что её оставили на столе. Светящийся экран не устанавливает блокировку ОС, закрытая дверца — запирание. Полномочия, личности, номинал и нормативные нарушения не размечаются.

Ответы сохраняются автоматически в `%LOCALAPPDATA%\Fortress\human-review-v1\review.sqlite3`. SQLite WAL, атомарные массовые операции, ревизии и история позволяют пережить закрытие браузера/перезапуск и отменять действия. Положение интерфейса также запоминается. При конфликте двух вкладок разметчик отвергает устаревшее изменение и предлагает обновить страницу.

Кнопка«Экспорт JSON» сохраняет снимок проверенных ответов с source SHA,PTS,time_base,исходным временем,значением,known-mask и human_approved. Сервер сохраняет неизменяемую копию снимка в `human-review-v1\exports`. Непросмотренные кадры не получают ответ автоматически, интервалы между ними не заполняются, исходная разметка/модели не меняются, обучение само не начинается. Экспорт не обязателен для продолжения работы: ответы уже лежат на ПК.

Подготовлено2464 исходных кадра с шагом0,5с из36 development-видео,13 вопросов. Четыре ранее зарезервированных источника исключены. Предсказания модели заранее не отмечены. Не требуется отвечать на все вопросы для всех кадров за один подход. Новая человеческая разметка создаёт новую ревизию обучающих/оценочных целей; её нельзя представлять независимой приёмкой или гарантией80%.

Кадры готовятся локально при первом открытии видео, затем берутся из проверенного кэша. Контекст кодируется локальным FFmpeg. Медиа, ответы, журналы и база находятся вне Git; API-ключ жюри разметчику не нужен. Сервер слушает только127.0.0.1, изменение ответов требует локальной cookie-сессии и того же Origin.

```powershell
# Другие пути или порт:
powershell -ExecutionPolicy Bypass -File tools/start_review.ps1 -TrainingRoot D:\FortressData\training-ready -DataRoot D:\FortressData\human-review-v1 -Port 8766

# Остановка без потери ответов:
powershell -ExecutionPolicy Bypass -File tools/stop_review.ps1
```

Реализация: `tools/label_review.py` и `tools/label_review_ui/`. Проверка сохранения,unknown,атомарности,конфликтов,отмены,экспорта и локального доступа: `.venv\Scripts\python.exe -B -m pytest tests/local/test_label_review.py -q`.

На настоящем сервере подтверждены2464 кадра/36 видео/13 вопросов, genuine JPEG, видеоконтекст с Range206 и доступность сервиса анализа на8000. Снимок интерфейса и машинные результаты находятся в `%LOCALAPPDATA%\Fortress\verification\human-review-v1`.

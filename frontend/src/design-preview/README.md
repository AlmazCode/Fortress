# Визуальный макет по референсу

В существующем Vite dev server откройте `/design-preview.html` (например, `http://127.0.0.1:5198/design-preview.html`). Запуск из frontend: `npm run dev -- --host 127.0.0.1 --port 5198 --strictPort`, остановка Ctrl+C.

Это отдельный экран для согласования структуры и оформления по изображению пользователя. Обычная страница `/`, транспорт API и реальная очередь не изменяются. `design-preview.html` не является entry производственной сборки; макет и его данные в стандартный `npm run build` не входят. CSS находится в отдельном entry и не импортируется основным приложением.

Структура: компактная шапка и логотип, демонстрационный доступ/модель, настройки и аватар; заголовок, demo notice и три показателя; полоса загрузки; таблицы очереди и результатов рядом; общий блок просмотра с иллюстрацией плеера, метками и карточками событий. В макете можно менять выбранный результат, открывать панели, ставить визуальную очередь на паузу, удалять строки и выбирать метки времени. Настоящий upload, анализ, авторизация, скачивание кадров и fullscreen не подключены.

Все числа, имена, состояния, проценты и события заданы для визуального примера. 12 обработанных и 8 найденных событий иллюстрируют сводку за условную смену; таблица показывает три последних примера. Нет нормативных документов или утверждений о реальном нарушении. Превью/плеер/кадры используют созданный ранее `presentation/synthetic-bank-lobby.png`: искусственный пустой зал, не реальная запись и не evidence. Ограничения загрузки оставлены совместимыми с текущим сервисом (200 МиБ / 180 с / Full HD / 60 fps), а не скопированы из картинки.

Макет адаптируется: Full HD — обе таблицы и плеер с событиями рядом; средний экран — последовательные секции, при 1300–1599 px длительность очереди доступна на превью, отдельный дублирующий столбец скрыт; телефон — карточки строк и вертикальный просмотр. Нативный dialog закрывается кнопкой/Escape и возвращает фокус. Нет внешних шрифтов, CDN, запросов к API/внешним сервисам или новых зависимостей.
